# คู่มือพนักงาน — ระบบ Smart Nurse Call (SNC)

> ฉบับใช้งานจริง — อัปเดต 13 ส.ค. 2569
> Dashboard: **https://nursecall.nithep.com**  (เข้าจากคอมหรือมือถือก็ได้)

---

## 1. เปิดใช้งานครั้งแรก (ทำแค่ครั้งเดียว)

1. เปิดเบราว์เซอร์ไปที่ `https://nursecall.nithep.com`
2. กดปุ่ม **⚙️ (การตั้งค่า)** มุมขวาบน
3. กรอก **API Key** ลงในช่อง *API Key* (ติดต่อผู้ดูแลระบบเพื่อขอ Key)
4. กด **บันทึก** — ตั้งค่าเสร็จ ใช้ปุ่มรับเรื่อง/เคลียร์สายได้ทันที

> 💡 ถ้าไม่กรอก Key จะ**ดู**หน้าจอได้ปกติ แต่กดปุ่มรับเรื่อง/เคลียร์สายไม่ได้ (ขึ้น 401)

---

## 2. หน้าจอหลัก (ส่วนประกอบ)

| ส่วน | อยู่ตรงไหน | ความหมาย |
|------|-----------|----------|
| **สถานะห้องพัก** | กลางจอ (บัตรห้อง) | สีเขียว = ปกติ, สีแดงกะพริบ = เรียกฉุกเฉิน |
| **แบนเนอร์แดง** | ด้านบนสุด | 🚨 มีสายค้าง — แสดงรายชื่อห้องที่กำลังเรียก |
| **KPI** | ใต้แบนเนอร์ | สถิติ: เวลารับเรื่องเฉลี่ย, ปฏิบัติตาม SLA |
| **ประวัติเหตุการณ์** | ล่างสุด | บันทึกการเรียกย้อนหลัง ค้นหา/กรอง/Export ได้ |
| **มุมขวาบน** | pill เขียว/เหลือง/แดง | สถานะการเชื่อมต่อ WebSocket (ฟีดสด) |

---

## 3. ทำงานประจำวัน

### 🚨 เมื่อมีสายเรียกฉุกเฉิน
1. แบนเนอร์แดงขึ้น + เสียงเตือนดัง + บัตรห้องกะพริบแดง
2. กดปุ่ม **🟡 รับเรื่อง** บนบัตรห้องนั้น (ยืนยันว่ารู้แล้ว)
3. ไปช่วยผู้ป่วย แล้วกลับมากด **✅ เคลียร์สาย** เมื่อเสร็จ

### 🔇 ปิดเสียงเตือนชั่วคราว
- กดปุ่ม **🔊** มุมขวาบน → เปลี่ยนเป็น 🔇 (เสียงเงียบ) — กดอีกครั้งเปิดใหม่

### 🔍 ค้นหาประวัติ
- ช่องค้นหามุมขวาบนของตารางประวัติ: พิมพ์เลขห้อง เช่น `0401`
- ปุ่มกรอง: ทั้งหมด / กำลังเรียก / รับเรื่องแล้ว / เสร็จสิ้น
- กด **Export CSV** เพื่อดาวน์โหลดเป็นไฟล์ Excel

### 🌐 สลับภาษา
- กดปุ่ม **EN** (มุมขวาบน) สลับไทย/อังกฤษ

---

## 4. เมื่อเจอปัญหา

| อาการ | ตรวจ | วิธีแก้ |
|-------|------|--------|
| จอแดง "ออฟไลน์" | เช็คเน็ต/ไฟ Pi | รอระบบเชื่อมต่อใหม่ (อัตโนมัติ) — เช็คเน็ตที่ห้องนางพยาบาล |
| กดปุ่มแล้วขึ้น 401 | API Key หาย | เปิด ⚙️ กรอก Key ใหม่ (ติดต่อผู้ดูแล) |
| จอไม่โหลด | เช็ค URL | เข้า `https://nursecall.nithep.com` (มี s ใน https) |
| เสียงไม่ดัง | เช็คระดับเสียงเครื่อง | กดปุ่ม 🔊 ให้เป็นเสียงเปิด แล้วเพิ่มเสียงเบราว์เซอร์ |
| สงสัยระบบพัง | — | แจ้งผู้ดูแลระบบทันที (มีระบบสำรองข้อมูลอัตโนมัติ) |

---

## 5. ข้อควรรู้
- **ห้องพักแสดงเป็น 4 หลัก** เช่น ห้อง 401 แสดงเป็น `0401`
- ระบบบันทึกประวัติอัตโนมัติทุกครั้งที่กดเรียก/รับเรื่อง/เคลียร์
- เวลา SLA เป้าหมาย: รับเรื่อง ≤ 30 วินาที, เคลียร์สาย ≤ 180 วินาที
- ข้อมูลสำรองถูกสร้างอัตโนมัติทุกวัน 03:00 น. (เก็บ 14 วัน)
