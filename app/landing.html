Features

ระบบที่ออกแบบมาเพื่อวิกฤตจริง

จากห้องพักผู้ป่วยถึงเคาน์เตอร์พยาบาล ทุกสัญญาณถูกส่งต่อแบบเรียลไทม์ พร้อมหลักฐานเชิงตัวเลขสำหรับ SLA

🔔

Real-time Alert

ผู้ป่วยกดปุ่ม ดึงสายฉุกเฉิน หรือยกหูโทรศัพท์ พยาบาลเห็นทันทีที่เคาน์เตอร์ด้วย Grid ห้องพักสีแดงกะพริบ

📡

SMDR ผ่าน Telnet

อ่านสัญญาณสดจากตู้ Phonik PBX (192.168.1.91:23) ถอดรหัสเป็น FHIR JSON โดย Listener บน Pi 4

🗺️

Dashboard ไทย/อังกฤษ

Grid ห้องพัก เขียว=ปกติ แดง=ฉุกเฉิน เหลือง=รับเรื่อง พร้อมเสียงเตือน Alarm และโหมดมืดระดับพรีเมียม

⏱️

SLA / Response Time

จับเวลาตั้งแต่ Alert จนกว่าพยาบาลจะ Acknowledge / Clear วัดประสิทธิภาพได้เชิงตัวเลข

☁️

Cloud + Edge

Pi 4 รัน local ใกล้ชิดฮาร์ดแวร์ Cloud Run เป็นสำรอง + แจ้งเตือน Telegram ผ่าน Cloudflare Tunnel

🛡️

FHIR Ready

Payload มาตรฐาน HL7 FHIR JSON ตั้งแต่วันแรก พร้อมต่อยอดขึ้น GCP Healthcare API / Vertex AI

How it works

วงจรการทำงาน 5 ขั้นตอน

ปิดจบตั้งแต่ผู้ป่วยกดปุ่ม จนพยาบาลกด Clear — ไร้ช่องโหว่ ไม่มีสัญญาณหลุด

01

Trigger

ผู้ป่วยกดปุ่ม / ดึงสายฉุกเฉิน / ยกหูโทรศัพท์จากห้องพัก

02

Capture

Phonik PBX พ่น SMDR Log ผ่าน TCP Telnet แบบเรียลไทม์

03

Process

Listener แปลงเป็น FHIR JSON + Outbox (idempotency) ลง SQLite

04

Broadcast

Backend ส่ง WebSocket กระจาย Alert ไปยัง Nurse Dashboard

05

Respond

พยาบาลรับเรื่อง + จับเวลา SLA จนกด Acknowledge / Clear

Architecture

สถาปัตยกรรม Edge-to-Cloud

แยกชัดเจนระหว่าง Edge (Pi 4), Cloud (GCP) และ Delivery — ทนทานต่อการหลุดของเครือข่าย

📍 Edge · Pi 4 192.168.1.94

  • Phonik PBX (SMDR Telnet :23)
  • snc_pbx_listener + Parser
  • event_outbox (idempotency)
  • snc-backend FastAPI :8000
  • SQLite WAL (local store)

☁️ Cloud · GCP Cloud Run

  • snc-cloud-backend (Firestore)
  • snc-alert-bridge (Telegram)
  • Secret Manager (3 secrets)
  • Cloud Monitoring + Uptime
  • Terraform IaC

🌐 Delivery Cloudflare

  • cloudflared tunnel (outbound)
  • snc.nithep.com
  • Nurse Dashboard (i18n TH/EN)
  • WebSocket realtime channel
  • Self-healing systemd units

เฮลท์แคร์ผู้สูงอายุ ที่ต้องการรีพอร์ตบริการแบบพรีเมี่ยม

สำหรับศูนย์ดูแลผู้สูงอายุและโรงพยาบาลจิตเวช SNC จับเวลาการตอบสนองพยาบาลทุกครั้ง พร้อมแพ็กเกจ รีพอร์ตบริการพรีเมี่ยม ที่แสดง SLA รายวัน/รายเดือน และ AI สรุปผู้บริหาร (Executive Summary) สำหรับผู้บริหาร ผู้กำกับดูแล และญาติผู้รับบริการ

  • 📈 รีพอร์ตการตอบสนองพยาบาล (Response Time) แยกตามช่วงเวลาและประเภทเหตุการณ์
  • 📑 สรุปผู้บริหารรายเดือน พร้อม AI วิเคราะห์จุดที่ต้องปรับปรุง
  • 🔒 ข้อมูลมาตรฐาน HL7 FHIR พร้อมส่งต่อผู้กำกับดูแล/กรมส่งเสริมคุณภาพ
  • 🤝 ทีมงานติดตั้ง บูรณาการ Phonik PBX และฝึกอบรมพร้อมรายงาน
